# v1.5.4

## 主要变化

- 子代理进度卡补上按 step 跟踪的 token 用量（输入、输出与上下文），Pi 子代理的用量事件会正确关联到对应进度，不再只看见工具调用状态。
- 超过 10 KB 的工具结果不再直接挤进进度卡或被静默截断：卡片保留简洁摘要，完整结果可从详情页分页查看。详情快照有大小、条目数与 TTL 限制，并继续校验聊天、话题、来源消息和操作用户。
- 改进文件编辑结果详情，展示路径及旧/新片段；敏感内容在展示前经过脱敏。失败或中断摘要仍会在折叠内容之外显示。
- 增加 Pi 子代理用量、详情分页、预算边界、过期与权限校验等回归测试。

## 验证

- `npm run check`：typecheck、Biome 与测试通过。
- `npm run test:coverage`：通过。
- `npm run build`：通过。

## 发布方式

本版本基于 `release/1.5.3` 发布，推送 `release/1.5.4` 分支与 `v1.5.4` 标签，不合入 `main`。
